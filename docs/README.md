# Tài liệu dự án punchAR

Cấu trúc theo dự án 3d_grapher.

| Thư mục | Nội dung |
|---|---|
| [`decisions/`](decisions/) | Sổ quyết định [`DECISIONS.md`](decisions/DECISIONS.md) và biên bản họp `YYYY-MM-DD_<nguồn>_<chủ-đề>.md` (mẫu: [`_template.md`](decisions/_template.md)) |
| [`planning/`](planning/) | Tổng quan dự án: bối cảnh, mục tiêu, kiến trúc, thiết kế game. [`PROJECT_OVERVIEW.vi.md`](planning/PROJECT_OVERVIEW.vi.md) cho nhóm, [`PROJECT_OVERVIEW.md`](planning/PROJECT_OVERVIEW.md) cho agent code (chưa đồng bộ với bản tiếng Việt) |
| [`sprints/`](sprints/) | Lộ trình, mốc lớn, thứ tự cắt việc ở [`README.md`](sprints/README.md); mỗi sprint một file `sprint-NN.md` (mẫu: [`_template.md`](sprints/_template.md)) |
| [`team/`](team/) | Phân công và chỗ giao nhau [`PHAN_CONG.vi.md`](team/PHAN_CONG.vi.md); code đặt ở đâu, thư mục nào của ai [`code-structure.md`](team/code-structure.md); nhánh, PR, tránh conflict [`gitflow.md`](team/gitflow.md); quy tắc làm việc với Unity [`unity-workflow.md`](team/unity-workflow.md) |
| [`weekly_report/`](weekly_report/) | Báo cáo tiến độ gửi giảng viên, đặt tên theo ngày báo cáo |
